# LaTeX Typesetting Portfolio

A self-created LaTeX portfolio sample demonstrating professional typesetting
for mathematical, academic, and technical documents.

## What this demonstrates
- Mathematical typesetting: equations, matrices, aligned derivations, SVD,
  block/state-space notation
- Technical figures: native TikZ/Pgfplots vector graphics (no raster images)
- Publication-style tables using `booktabs`
- Cross-referenced document structure (figures, tables, equations)
- Clean two-column academic layout

## Contents
- `main.tex` — the LaTeX source
- `hashmi_labs___LaTeX_Typesetting_Portfolio.pdf` — the compiled output

## Compile it yourself
```bash
pdflatex main.tex
```
Requires a standard TeX distribution (TeX Live / MiKTeX) with `amsmath`,
`booktabs`, `tikz`, `pgfplots`, and `hyperref` — all standard packages,
no exotic dependencies.

## Note
This is a self-created portfolio sample intended to demonstrate typesetting
capability. It is not presented as commissioned client work or a published
research paper.
